Clima HermosilloClima / Hermosillo

Objetivo del proyecto

Consultar una API externa, guardar sus datos y mostrarlos en un dashboard.

Paso 1
Consultar

Condiciones actuales estimadas y pronósticos para una ubicación fija.

Paso 2
Conservar

Capturas periódicas y versiones de los pronósticos dentro de PostgreSQL.

Paso 3
Comparar

Diferencias entre valores actuales y predicciones hechas con un día de anticipación.

El proyecto consume predicciones externas; no entrena un modelo propio.

Proceso de recolección

Coordenadas fijas y zona horaria America/Hermosillo.

01ConsultarDos peticiones: clima actual y predicciones anteriores.
02TransformarFechas, series horarias y alineación de valores.
03GuardarTres tablas en una sola transacción de PostgreSQL.
04Esperar600 segundos al terminar; después, repetir.

Timeout HTTP de 30 s. Si ocurre un error, se registra y se reintenta en el siguiente ciclo.

Modelo de datos

Identificadores e índices temporales; sin claves foráneas entre tablas.

observations

¿Qué valor tenemos ahora?

  • fetched_at · observed_at
  • temperature · humidity
  • apparent_temperature
  • precipitation · wind_speed
forecasts

¿Qué esperábamos para cada hora?

  • fetched_at · forecast_for
  • temperature · precipitation
  • precipitation_probability
  • UNIQUE (captura, hora destino)
comparisons

¿Cuánto cambió la predicción?

  • fetched_at · valid_hour
  • current_temperature
  • predicted_temperature_24h
  • lluvia actual y predicha

Clima HermosilloMejoras posibles

Limitaciones

Puntos a considerar al interpretar los resultados y para trabajo futuro.

Horizonte del pronóstico

Tres días solicitados no garantizan 72 horas futuras completas.

Comparación temporal

La temperatura actual puede no coincidir con la hora redondeada.

Dependencia externa

Si falla la segunda API, tampoco se guarda la captura actual.

Paso a producción

Gestionar secretos, migraciones, retención y monitoreo.
